LOKA BOARDGAME CAFE
Progres III – Pengembangan Website CMS

Deskripsi Proyek

Pada Progres III, website Loka Boardgame Cafe dikembangkan dari website katalog dan pemesanan menjadi website berbasis **Content Management System (CMS)**. Pengembangan ini mencakup fitur Article, Category, Pages, Hero Section, Web Settings, dan Networkings.
Selain itu, dilakukan peningkatan tampilan website, penambahan informasi pada footer, serta integrasi booking meja, pemilihan boardgame, dan pemesanan makanan/minuman dalam satu proses checkout.

Hasil Pengembangan

Website Loka Boardgame Cafe memiliki sistem pengelolaan konten yang memungkinkan admin memperbarui informasi website, artikel, kategori, tampilan Hero Section, dan jejaring sosial tanpa mengubah kode secara langsung. Dari sisi pelanggan, proses booking meja, pemilihan boardgame, dan pemesanan menu telah diintegrasikan untuk meningkatkan efisiensi layanan.

Kesimpulan
Pengembangan Progres III bertujuan meningkatkan fungsionalitas, kemudahan pengelolaan konten, serta pengalaman pengguna sehingga website Loka Boardgame Cafe menjadi lebih informatif, interaktif, dan profesional.
